💰 Chi phí Vận hành 0 USD (Serverless)

Tận dụng 100% Google Workspace sẵn có: Drive (Lưu tệp), Sheets (Cơ sở dữ liệu), Gmail (Gửi thư), Apps Script (Backend). Không tốn chi phí thuê máy chủ (VPS/Cloud) hàng tháng.

⚡ Trải nghiệm Siêu tốc & Bảo mật Enterprise

• Giao diện Vanilla JS siêu nhẹ (~50KB), RAM Cache phản hồi 0ms.
• Hỗ trợ Dark/Light Theme (Zero-FOUC).
• Đăng nhập Single Sign-On kép: Google Workspace & Microsoft Azure AD.
